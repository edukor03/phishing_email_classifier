# ML Model Training

In this folder ML model was trained and text was analysed and preprocessed before being used for training.

## Folder structure

- data (stores data)
- models (Hidden here, but stores trained models)
- training.ipynb (Used for training ML models)
- processing_dataset.ipynb (Used for analysing and process text)

## Models trained

1. Logistic Regression - Had best performance
2. Random Forest
3. Naive Bayes
